# Tactile Math Learning Companion

ESP32-based tactile math learning device for blind and visually impaired students. Users enter numbers with 0–9 push buttons and receive the output as a physical six-dot Braille pattern driven by servo motors. Built to make basic math more accessible using low-cost, inclusive hardware.

## Features

- Tactile number input via 0–9 push buttons  
- Braille output using 6 servo-driven dots  
- Enter, Next, and Change buttons for navigation  
- ESP32-based control logic mapping numbers to Braille patterns  

## Hardware

- ESP32  
- 10 push buttons (0–9)  
- 3 control buttons (Enter, Next, Change)  
- 6 servo motors  
- Breadboard, jumper wires, external power supply  

## Firmware

- Platform: Arduino IDE / ESP32  
- Language: C++  

## Usage

1. Power the ESP32 and circuit.  
2. Press a number button (0–9).  
3. Press Enter to confirm.  
4. Feel the Braille pattern formed by the servos.  
5. Use Next/Change to navigate or correct input.
